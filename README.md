# SECORO thesis proposal

LaTeX template for bachelor and master thesis proposals at [SECORO](https://secoro.uni-bremen.de/), University of Bremen.

Select the thesis type via the class option, `\documentclass[master]{thesis_proposal}` or `\documentclass[bachelor]{thesis_proposal}`.

Please make sure to change name of the file to match the naming convention, i.e. first letter of your first name followed by your last name, e.g. `JDoe-ThesisProposal.tex`
